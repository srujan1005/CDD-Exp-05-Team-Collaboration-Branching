# CDD Lab Experiment 5: Team Collaboration with GitHub and Branching Strategies

## Objective
Collaborate on a team project using GitHub repositories and branching strategies.

## Duration
2 Hours

## Tasks
1. Set up a shared repository.
2. Implement a branching strategy (e.g., Git Flow or GitHub Flow).
3. Create feature branches for different team members.
4. Practice collaborative workflows with pull requests.
5. Handle concurrent changes.

## Branching Strategies
- **GitHub Flow**: main + feature branches
- **Git Flow**: main, develop, feature, release, hotfix

## Expected Outcome
A collaborative workflow demonstrated with multiple branches and pull requests.
